Securtek — installazione client Mac
====================================

Modo semplice (consigliato)
---------------------------
Usa lo zip autoinstallante:

  dist/Securtek-client-mac-vVERSION.zip

1. Copia lo zip sul Mac client e estrailo.
2. Doppio clic su "Installa Securtek".
   Se macOS blocca: tasto destro → Apri → Apri.
3. Segui le finestre guidate:
   - controllo Python (se manca: Installa strumenti Apple)
   - controllo Edge/Chrome
   - URL del Mac Mini
4. Securtek.app comparira sul Desktop

File unico (AirDrop): InstallaSecurtek.command
  Se dice che non hai i privilegi:

  bash ~/Downloads/InstallaSecurtek.command

Se manca Python
---------------
Nell installer premi "Installa strumenti Apple", conferma nella
finestra Apple, attendi, poi "Continua".
Oppure installa Python da https://www.python.org/downloads/
e rilancia l installer.

Verifica helper:

  curl http://127.0.0.1:18765/health

Log installer:

  ~/Library/Logs/Securtek/install-client.log
