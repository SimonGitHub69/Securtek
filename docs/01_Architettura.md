# Architettura Securtek

## Stack tecnologico

- Python 3.13
- Django 6
- PostgreSQL 18
- Bootstrap 5
- Tabler
- Git
- Visual Studio Code

## Struttura del progetto

- config      → configurazione Django
- core        → framework comune
- clienti     → gestione clienti
- tecnici     → gestione tecnici
- pratiche    → gestione pratiche
- calendario  → agenda e pianificazione
- docs        → documentazione tecnica
- media       → file caricati dagli utenti
- static      → CSS, JavaScript, immagini
- templates   → template HTML
- tests       → test automatici

## Principi

- Codice pulito
- Riutilizzo del codice
- Convenzioni coerenti
- Documentazione continua
- Modularità
