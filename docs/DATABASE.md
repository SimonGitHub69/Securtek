# DATABASE

## Dominio Anagrafiche

### Entità principale

Soggetto

Un soggetto rappresenta qualsiasi persona fisica o giuridica che interagisce con il sistema.

Può assumere uno o più ruoli.

Esempi:

- Cliente
- Tecnico
- Fornitore
- Compagnia Assicurativa
- Perito
- Studio Legale

---

## Entità correlate

- Contatti
- Indirizzi
- Note
- Allegati
- Pratiche

---

## Principio

Una sola anagrafica.

Più ruoli.
